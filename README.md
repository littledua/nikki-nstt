# Nikki Diary

Sổ tay tiếng Việt cho người chơi Ngôi Sao Thời Trang (server VN).

- **Lịch sự kiện:** sự kiện đang mở, sắp mở và tra lại các năm trước.
- **Phối đồ:** gợi ý bộ điểm gốc cao nhất cho các chủ đề Khu Thi Đấu (chưa tính kỹ năng).
- **Tủ đồ:** nhập file `clothes_date` để chỉ gợi ý đồ bạn có; tra cứu toàn bộ đồ, đánh dấu món đã có.
- **Bộ đã lưu:** lưu bộ phối, đặt tên, mở lại.

Nguồn dữ liệu và giấy phép: xem mục **Nguồn** trên web. File `du-lieu.json` chia sẻ theo CC BY-SA 3.0.

Web làm cho vui, không liên quan nhà phát hành.
