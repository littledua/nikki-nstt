Web phối đồ tiếng Việt cho game Ngôi Sao Thời Trang (server VN).

- **Tủ đồ:** nhập file `clothes_date` lấy từ Nox, xem và lọc toàn bộ đồ, đánh dấu món đã có.
- **Phối đồ:** chọn ải (Thiếu Nữ, Công Chúa, Ải Hội, Khu Thi Đấu, hoặc tự đặt trọng số) để xem bộ điểm cao nhất từ đồ đang có.
- Mọi tên gọi (phong cách, loại đồ, tag, kỹ năng, loại ải) theo đúng chữ trong game NSTT; bảng đối chiếu ở `docs/thuat-ngu.md`.
- **Bộ đã lưu:** lưu bộ phối, đặt tên, mở lại để chỉnh.

Web làm cho vui, không liên quan nhà phát hành.
