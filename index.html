Nhập tủ đồ

Kéo thả file clothes_date vào đâyhoặc bấm để chọn. File chỉ đọc trên máy bạn, không gửi đi đâu.

Cách lấy file tủ đồ

Cần máy tính có giả lập Android (Nox, LDPlayer hoặc BlueStacks). Điện thoại thật không lấy được, vì file nằm trong thư mục hệ thống của game, phải bật Root mới mở được.
  1. Cài giả lập và bật Root.
    • Nox: Cài đặt → Cơ bản → bật Root, khởi động lại Nox.
    • LDPlayer: Cài đặt → Cài đặt khác → Quyền ROOT → Bật, khởi động lại.
    • BlueStacks không có nút bật Root sẵn nên khó làm, bạn nên dùng Nox hoặc LDPlayer.
  2. Mở game trong giả lập, đăng nhập đúng tài khoản, vào Tủ đồ một lần cho game lưu dữ liệu, rồi tắt game.
  3. Cài app quản lý file trong giả lập (vd. Amaze File Manager trên CH Play). Khi app hỏi quyền Root thì bấm Cho phép.
  4. Tìm file: trong app, đi tới thư mục
    /data/data/com.vng.ngoisaothoitrang/files/usrdat
    Chọn file có tên bắt đầu bằng clothes_date (đuôi là dãy số tài khoản). Không lấy file furniture_date.
  5. Chép file ra máy tính qua thư mục chia sẻ của giả lập:
    • Nox: dán file vào /mnt/shared/Other, trên máy tính mở thư mục Nox_share sẽ thấy file.
    • LDPlayer: dán file vào thư mục Pictures, trên máy tính bấm nút Thư mục chia sẻ ở thanh bên của LDPlayer để mở.
  6. Quay lại trang này, kéo thả file vào ô Nhập tủ đồ (hoặc bấm vào ô để chọn file). Xong!

Có đồ mới thì làm lại bước 2, 4, 5, 6 để cập nhật. File chỉ đọc trên máy bạn, web không gửi đi đâu.

Trang cuối sổ

Nguồn dữ liệu và Credit.

Cảm ơn những nguồn đã giúp cuốn sổ này có dữ liệu.

Nguồn dữ liệu

  • Điểm món đồ, ô đồ, tên bộ đồ và tên chặng: tổng hợp thủ công từ game. Món còn thiếu bổ sung từ Love Nikki Wiki theo giấy phép CC BY-SA 3.0; điểm chữ đã quy đổi sang số để tính.
  • Luật trừ điểm trang sức: theo Love Nikki Wiki, trang Styling Battle (CC BY-SA 3.0).
  • Trọng số chủ đề Khu Thi Đấu: chép từ thông tin công khai trong game.
  • Ải bắt buộc và công thức chế: theo Love Nikki Wiki, trang Target Suits và trang từng món (CC BY-SA 3.0), đã đổi sang tên Việt.
  • Lịch sự kiện, ảnh banner, cách chơi và tổn thất (chi phí): lấy tham khảo từ các page Ngôi Sao Thời Trang VNG, My Miracle Nikki và Kỳ Tích Noãn Noãn. Phần "Dự đoán theo bản Trung" dựa theo thông tin từ page Kỳ Tích Noãn Noãn, nên tên, giá và ngày khi về bản Việt có thể chênh một chút.
  • Hình món đồ: icon từ 奇迹暖暖 BWIKI (bilibili); một số hình chụp từ game.

Về điểm số

  • Điểm trên web là điểm gốc ước tính, chưa tính kỹ năng khi thi, có thể lệch so với điểm thật trong game.
  • Web so các món với nhau để chọn bộ tốt nhất, nên bộ gợi ý vẫn dùng được dù điểm tổng lệch.

Giấy phép

  • Phần dữ liệu quy đổi từ Love Nikki Wiki được chia sẻ lại theo cùng giấy phép CC BY-SA 3.0.
  • Ngôi Sao Thời Trang thuộc VNG / Paper Games. Web làm cho vui, không liên quan nhà phát hành.

Kết nối GitHub để lưu thẳng lên web

Đã kết nối thì bấm Lưu là web tự đưa ảnh vào thư mục ev và sửa thẳng su-kien.txt và du-doan.txt. Chưa kết nối thì web soạn sẵn dòng, tải ảnh về máy và chỉ chỗ dán trên GitHub.

Cách lấy mã: vào GitHub › Fine-grained token. Ở mục Repository access chọn Only select repositories › nikki-nstt. Ở mục Permissions › Contents chọn Read and write. Bấm Generate token rồi chép mã dán vào đây.

Mã chỉ lưu trong trình duyệt này và chỉ gửi tới GitHub. Đừng lưu mã trên máy dùng chung.
