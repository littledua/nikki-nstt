File này lấy ở đâu?
  1. Bật Root trong cài đặt Nox (tab Cơ bản).
  2. Mở game, vào Tủ đồ cho game tải dữ liệu, rồi tắt game.
  3. Mở Amaze, vào /data/data/com.vng.ngoisaothoitrang/files/usrdat
  4. Sao chép file clothes_date… sang /mnt/shared/Other, rồi lấy ra từ thư mục Nox_share trên máy tính.
